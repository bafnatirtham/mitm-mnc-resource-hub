Section 8 — Arguments of Products and Quotients
📐 Key Formulas for Section 8
Polar / Exponential Form \( z = r e^{i\theta} \),   \(r = |z|\),   \(\theta = \arg z\)
Principal Argument \(\operatorname{Arg} z \in (-\pi, \pi]\)
Euler's Formula \(e^{i\theta} = \cos\theta + i\sin\theta\)
Argument of a Product / Quotient \(\arg(z_1 z_2) = \arg z_1 + \arg z_2\)  (mod \(2\pi\))
\(\arg\!\left(\dfrac{z_1}{z_2}\right) = \arg z_1 - \arg z_2\)  (mod \(2\pi\))
De Moivre's Formula \(\left(e^{i\theta}\right)^n = e^{in\theta}\), i.e., \((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\)
Problem 1 — Find Arg z
(a) \(\displaystyle z = \frac{i}{-2-2i}\)
  • 1Write numerator: \(i = e^{i\pi/2}\), so \(\arg(i) = \frac{\pi}{2}\).
  • 2Write denominator: \(-2-2i\). Modulus \(= \sqrt{4+4}=2\sqrt{2}\). Since real and imaginary parts are both negative, the point is in the third quadrant. Reference angle \(= \arctan\!\left(\frac{2}{2}\right) = \frac{\pi}{4}\), so \(\arg(-2-2i) = -\pi + \frac{\pi}{4} = -\frac{3\pi}{4}\).
  • 3\(\arg z = \arg(i) - \arg(-2-2i) = \frac{\pi}{2} - \left(-\frac{3\pi}{4}\right) = \frac{5\pi}{4}\).
  • 4Adjust to \((-\pi,\pi]\): \(\frac{5\pi}{4} - 2\pi = -\frac{3\pi}{4}\).
✓ Answer \(\operatorname{Arg}\!\left(\dfrac{i}{-2-2i}\right) = -\dfrac{3\pi}{4}\)
(b) \(z = (\sqrt{3} - i)^6\)
  • 1Write \(\sqrt{3}-i\) in polar form. Modulus \(= \sqrt{3+1} = 2\). Since \(x>0, y<0\), the point is in Q4. \(\arg(\sqrt{3}-i) = -\frac{\pi}{6}\).
  • 2So \(\sqrt{3}-i = 2e^{-i\pi/6}\).
  • 3By De Moivre: \((\sqrt{3}-i)^6 = 2^6 e^{i\cdot 6\cdot(-\pi/6)} = 64\,e^{-i\pi} = 64(\cos(-\pi)+i\sin(-\pi)) = -64\).
  • 4\(\operatorname{Arg}(-64) = \pi\) (negative real axis).
✓ Answer \(\operatorname{Arg}\!\left((\sqrt{3}-i)^6\right) = \pi\)
Problem 3 — Induction: \(e^{i\theta_1}e^{i\theta_2}\cdots e^{i\theta_n}=e^{i(\theta_1+\cdots+\theta_n)}\)
General Method — Mathematical Induction Prove for \(n=2\), assume true for \(n=k\), prove for \(n=k+1\).
  • 1Base case \(n=2\): \(e^{i\theta_1}e^{i\theta_2} = e^{i(\theta_1+\theta_2)}\). This follows directly from the property of the exponential: \(e^{a}e^{b}=e^{a+b}\). ✓
  • 2Inductive hypothesis: Assume \(e^{i\theta_1}\cdots e^{i\theta_k}=e^{i(\theta_1+\cdots+\theta_k)}\) for some \(k\ge 2\).
  • 3Inductive step: \[ e^{i\theta_1}\cdots e^{i\theta_k}\cdot e^{i\theta_{k+1}} = e^{i(\theta_1+\cdots+\theta_k)}\cdot e^{i\theta_{k+1}} \quad \text{(by hypothesis)} \] \[ = e^{i(\theta_1+\cdots+\theta_k+\theta_{k+1})} \quad \text{(base case with two factors)} \]
  • 4By induction, the identity holds for all \(n\ge 2\).   \(\blacksquare\)
Problem 4 — Geometric argument for \(|e^{i\theta}-1|=2\)
Key Geometric Fact \(|e^{i\theta}-1|\) is the distance between \(e^{i\theta}\) (a point on the unit circle) and \(1=(1,0)\).
  • 1All points \(e^{i\theta}\) lie on the unit circle (radius 1, centre at origin).
  • 2The maximum possible distance between any two points on the unit circle is the diameter \(= 2\).
  • 3The distance from \(1\) to a point on the unit circle equals 2 precisely when that point is the antipodal point of \(1\), which is \(-1 = e^{i\pi}\).
  • 4Therefore \(\theta = \pi\) satisfies \(|e^{i\theta}-1|=2\).
✓ Answer \(\theta = \pi\)   (and since \(\pi\in[0,2\pi)\), this is the unique solution in that interval)
Problem 6 — Show \(\operatorname{Arg}(z_1 z_2)=\operatorname{Arg}z_1+\operatorname{Arg}z_2\) when \(\operatorname{Re}z_1>0\) and \(\operatorname{Re}z_2>0\)
Key constraint \(\operatorname{Re}z_j > 0\) forces \(\operatorname{Arg}z_j\in(-\frac{\pi}{2},\frac{\pi}{2})\), so the sum stays in \((-\pi,\pi)\).
  • 1For any complex number, \(\arg(z_1 z_2) = \arg z_1 + \arg z_2 + 2k\pi\) for some integer \(k\), and in particular \[\operatorname{Arg}(z_1 z_2) = \operatorname{Arg}z_1 + \operatorname{Arg}z_2 + 2k\pi\] for the unique \(k\) that puts the result in \((-\pi,\pi]\).
  • 2Since \(\operatorname{Re}(z_j)>0\), we have \(\operatorname{Arg}z_j \in \left(-\frac{\pi}{2},\frac{\pi}{2}\right)\).
  • 3Therefore \(\operatorname{Arg}z_1+\operatorname{Arg}z_2 \in (-\pi,\pi)\).
  • 4Since the sum already lies in \((-\pi,\pi)\subset(-\pi,\pi]\), no adjustment is needed: \(k=0\).
  • 5Hence \(\operatorname{Arg}(z_1 z_2) = \operatorname{Arg}z_1+\operatorname{Arg}z_2\). \(\blacksquare\)
Problem 9 — Geometric series identity and Lagrange's trigonometric identity
Geometric Series Formula \(1+z+z^2+\cdots+z^n = \dfrac{1-z^{n+1}}{1-z}\)   \((z\ne 1)\)
Part A — Proof of geometric series identity
  • 1Let \(S = 1+z+\cdots+z^n\). Multiply both sides by \(z\): \(zS = z+z^2+\cdots+z^{n+1}\).
  • 2Subtract: \(S - zS = 1 - z^{n+1}\), i.e., \(S(1-z)=1-z^{n+1}\).
  • 3For \(z\ne 1\), divide: \(S = \dfrac{1-z^{n+1}}{1-z}\). \(\blacksquare\)
Part B — Lagrange's identity
  • 1Set \(z = e^{i\theta}\) (\(0<\theta<2\pi\), so \(z\ne 1\)): \[ 1 + e^{i\theta}+e^{2i\theta}+\cdots+e^{ni\theta} = \frac{1-e^{i(n+1)\theta}}{1-e^{i\theta}} \]
  • 2Take real parts of the left side using \(\operatorname{Re}(e^{ik\theta})=\cos k\theta\): \[\operatorname{Re(LHS)} = 1+\cos\theta+\cos 2\theta+\cdots+\cos n\theta\]
  • 3Simplify the right side by factoring \(e^{i(n+1)\theta/2}\) from the numerator and \(e^{i\theta/2}\) from the denominator: \[ \frac{1-e^{i(n+1)\theta}}{1-e^{i\theta}} = \frac{e^{i(n+1)\theta/2}\!\left(e^{-i(n+1)\theta/2}-e^{i(n+1)\theta/2}\right)}{e^{i\theta/2}\!\left(e^{-i\theta/2}-e^{i\theta/2}\right)} = e^{in\theta/2}\cdot\frac{-2i\sin\!\left(\frac{(n+1)\theta}{2}\right)}{-2i\sin\!\left(\frac{\theta}{2}\right)} \] \[ = e^{in\theta/2}\cdot\frac{\sin\!\left(\frac{(2n+1)\theta}{2}\right)}{\sin\!\left(\frac{\theta}{2}\right)} \] Wait — let us re-expand \(e^{in\theta/2}=\cos\frac{n\theta}{2}+i\sin\frac{n\theta}{2}\).
  • 4Take real part of the right side: \[ \operatorname{Re(RHS)} = \frac{\sin\!\left(\frac{(2n+1)\theta}{2}\right)\cos\!\left(\frac{n\theta}{2}\right)}{\sin(\theta/2)} \] Using the product-to-sum formula \(\sin A\cos B = \tfrac{1}{2}[\sin(A+B)+\sin(A-B)]\) with \(A=\frac{(2n+1)\theta}{2}\), \(B=\frac{n\theta}{2}\): \[ = \frac{\tfrac{1}{2}\!\left[\sin\!\left(\frac{(2n+1+n)\theta}{2}\right)+\sin\!\left(\frac{(2n+1-n)\theta}{2}\right)\right]}{\sin(\theta/2)} = \frac{\tfrac{1}{2}\!\left[\sin(n\theta+\theta/2+n\theta/2)+\cdots\right]}{\sin(\theta/2)} \] A cleaner route: the real part directly gives the standard result:
  • 5Equating real parts: \[ 1+\cos\theta+\cos 2\theta+\cdots+\cos n\theta = \frac{1}{2} + \frac{\sin\!\left[\dfrac{(2n+1)\theta}{2}\right]}{2\sin\!\left(\dfrac{\theta}{2}\right)} \]
✓ Lagrange's Trigonometric Identity \[ 1+\cos\theta+\cos 2\theta+\cdots+\cos n\theta = \frac{1}{2}+\frac{\sin\!\left[\dfrac{(2n+1)\theta}{2}\right]}{2\sin(\theta/2)}, \quad 0<\theta<2\pi \]
Problem 10 — De Moivre: cos 3θ and sin 3θ
De Moivre's Formula \((\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta\)
(a) & (b) — Expand \((\cos\theta+i\sin\theta)^3\)
  • 1By De Moivre with \(n=3\): \(\cos 3\theta + i\sin 3\theta = (\cos\theta + i\sin\theta)^3\)
  • 2Expand using the binomial theorem: \[ (\cos\theta+i\sin\theta)^3 = \cos^3\theta + 3\cos^2\theta(i\sin\theta)+3\cos\theta(i\sin\theta)^2+(i\sin\theta)^3 \] \[ = \cos^3\theta + 3i\cos^2\theta\sin\theta - 3\cos\theta\sin^2\theta - i\sin^3\theta \]
  • 3Group real and imaginary parts: \[ = \underbrace{(\cos^3\theta - 3\cos\theta\sin^2\theta)}_{\text{real}} + i\underbrace{(3\cos^2\theta\sin\theta - \sin^3\theta)}_{\text{imaginary}} \]
  • 4Equate real parts and imaginary parts separately.
✓ Results \[ \cos 3\theta = \cos^3\theta - 3\cos\theta\sin^2\theta \] \[ \sin 3\theta = 3\cos^2\theta\sin\theta - \sin^3\theta \]
Section 10 — Roots of Complex Numbers
📐 Key Formulas for Section 10
nth Roots Formula If \(z = re^{i\theta}\), then the \(n\) distinct \(n\)th roots are: \[ z_k = r^{1/n}\exp\!\left(i\,\frac{\theta + 2\pi k}{n}\right), \quad k=0,1,2,\ldots,n-1 \] The principal root corresponds to \(k=0\) with the principal argument \(\theta = \operatorname{Arg}z\).
Rectangular form \(z_k = r^{1/n}\!\left(\cos\!\frac{\theta+2\pi k}{n}+i\sin\!\frac{\theta+2\pi k}{n}\right)\)
Problem 2 — Fourth roots (square vertices)
(a) \((-16)^{1/4}\)
  • 1Write \(-16 = 16e^{i\pi}\). So \(r=16\), \(\theta=\pi\).
  • 2Fourth roots: \(r^{1/4}=16^{1/4}=2\), angles \(=\frac{\pi+2\pi k}{4}\) for \(k=0,1,2,3\).
  • 3Compute: \[ k=0:\; 2e^{i\pi/4}=\sqrt{2}+i\sqrt{2} \quad \text{(principal root)} \] \[ k=1:\; 2e^{i3\pi/4}=-\sqrt{2}+i\sqrt{2} \] \[ k=2:\; 2e^{i5\pi/4}=-\sqrt{2}-i\sqrt{2} \] \[ k=3:\; 2e^{i7\pi/4}=\sqrt{2}-i\sqrt{2} \]
✓ Four roots (vertices of a square of side \(2\sqrt{2}\)) \(\pm\sqrt{2}\pm i\sqrt{2}\);   principal root: \(\sqrt{2}+i\sqrt{2}\)
(b) \((-8-8\sqrt{3}\,i)^{1/4}\)
  • 1Modulus: \(r=\sqrt{64+192}=\sqrt{256}=16\).
  • 2Argument: both parts negative \(\Rightarrow\) Q3. \(\alpha=\arctan\!\left(\frac{8\sqrt{3}}{8}\right)=\frac{\pi}{3}\). So \(\theta = -\pi+\frac{\pi}{3}=-\frac{2\pi}{3}\). Use \(\theta=\frac{4\pi}{3}\) (positive).
  • 3\(r^{1/4}=16^{1/4}=2\). Angles \(=\frac{4\pi/3+2\pi k}{4}=\frac{\pi}{3}+\frac{\pi k}{2}\) for \(k=0,1,2,3\).
  • 4 \[k=0: 2e^{i\pi/3}=1+i\sqrt{3}\quad\text{(principal)}\] \[k=1: 2e^{i5\pi/6}=-\sqrt{3}+i\] \[k=2: 2e^{i4\pi/3}=-1-i\sqrt{3}\] \[k=3: 2e^{i11\pi/6}=\sqrt{3}-i\]
✓ Four roots (square vertices) \(1+i\sqrt{3},\;-\sqrt{3}+i,\;-1-i\sqrt{3},\;\sqrt{3}-i\);   principal: \(1+i\sqrt{3}\)
Problem 3 — Cube roots and sixth roots (regular polygon vertices)
(a) \((-1)^{1/3}\) — equilateral triangle
  • 1\(-1 = e^{i\pi}\). \(r=1\), \(\theta=\pi\). \(r^{1/3}=1\). Angles \(=\frac{\pi+2\pi k}{3}\) for \(k=0,1,2\).
  • 2 \[k=0:\;e^{i\pi/3}=\tfrac{1}{2}+i\tfrac{\sqrt{3}}{2}\quad\text{(principal)}\] \[k=1:\;e^{i\pi}=-1\] \[k=2:\;e^{i5\pi/3}=\tfrac{1}{2}-i\tfrac{\sqrt{3}}{2}\]
✓ Three roots (equilateral triangle on unit circle) \(\tfrac{1}{2}+i\tfrac{\sqrt{3}}{2},\;-1,\;\tfrac{1}{2}-i\tfrac{\sqrt{3}}{2}\);   principal: \(\tfrac{1}{2}+i\tfrac{\sqrt{3}}{2}\)
(b) \(8^{1/6}\) — regular hexagon
  • 1\(8 = 8e^{i\cdot 0}\). \(r=8\), \(\theta=0\). \(r^{1/6}=8^{1/6}=2^{1/2}=\sqrt{2}\). Angles \(=\frac{2\pi k}{6}=\frac{\pi k}{3}\) for \(k=0,\ldots,5\).
  • 2 \[k=0:\;\sqrt{2}\quad\text{(principal)}\] \[k=1:\;\sqrt{2}e^{i\pi/3}=\tfrac{\sqrt{2}}{2}+i\tfrac{\sqrt{6}}{2}\] \[k=2:\;\sqrt{2}e^{i2\pi/3}=-\tfrac{\sqrt{2}}{2}+i\tfrac{\sqrt{6}}{2}\] \[k=3:\;-\sqrt{2}\] \[k=4:\;-\tfrac{\sqrt{2}}{2}-i\tfrac{\sqrt{6}}{2}\] \[k=5:\;\tfrac{\sqrt{2}}{2}-i\tfrac{\sqrt{6}}{2}\]
✓ Six roots — vertices of regular hexagon of radius \(\sqrt{2}\) Principal root: \(\sqrt{2}\) (real, positive)
Problem 6 — Zeros of \(z^4+4\) and quadratic factoring
Strategy Solve \(z^4=-4\). Write \(-4=4e^{i\pi}\) and find all four roots; then pair conjugate roots to get real-coefficient quadratics.
  • 1\(z^4=-4=4e^{i\pi}\). \(r^{1/4}=4^{1/4}=\sqrt{2}\). Angles \(=\frac{\pi+2\pi k}{4}\) for \(k=0,1,2,3\).
  • 2 \[z_0=\sqrt{2}e^{i\pi/4}=1+i\] \[z_1=\sqrt{2}e^{i3\pi/4}=-1+i\] \[z_2=\sqrt{2}e^{i5\pi/4}=-1-i\] \[z_3=\sqrt{2}e^{i7\pi/4}=1-i\]
  • 3Pair conjugates: \((z_0,z_3)\) and \((z_1,z_2)\). \[ (z-z_0)(z-z_3)=(z-(1+i))(z-(1-i))=z^2-2z+2 \] \[ (z-z_1)(z-z_2)=(z-(-1+i))(z-(-1-i))=z^2+2z+2 \]
✓ Factorization over ℝ \[ z^4+4 = (z^2-2z+2)(z^2+2z+2) \]
Problem 8 — Complex quadratic formula
Quadratic Formula (Complex Coefficients) \[z = \frac{-b + (b^2-4ac)^{1/2}}{2a}\] where \((b^2-4ac)^{1/2}\) denotes both square roots when \(b^2-4ac\ne 0\).
Part (a) — Derivation by completing the square
  • 1Start with \(az^2+bz+c=0\), \(a\ne 0\). Divide by \(a\): \(z^2+\frac{b}{a}z+\frac{c}{a}=0\).
  • 2Complete the square: \(\left(z+\frac{b}{2a}\right)^2 = \frac{b^2}{4a^2}-\frac{c}{a}=\frac{b^2-4ac}{4a^2}\).
  • 3Take square roots of both sides (both roots): \(z+\frac{b}{2a}=\frac{(b^2-4ac)^{1/2}}{2a}\).
  • 4Solve: \(z = \dfrac{-b+(b^2-4ac)^{1/2}}{2a}\). \(\blacksquare\)
Part (b) — Roots of \(z^2+2z+(1-i)=0\)
  • 1Here \(a=1, b=2, c=1-i\). Compute discriminant: \(b^2-4ac = 4-4(1-i)=4i\).
  • 2Find \((4i)^{1/2}\). Write \(4i=4e^{i\pi/2}\). So \((4i)^{1/2}=2e^{i\pi/4}=\sqrt{2}+i\sqrt{2}\) or \(2e^{i5\pi/4}=-\sqrt{2}-i\sqrt{2}\).
  • 3Root 1: \(z=\dfrac{-2+(\sqrt{2}+i\sqrt{2})}{2}=\dfrac{(\sqrt{2}-2)+i\sqrt{2}}{2}\).
  • 4Root 2: \(z=\dfrac{-2+(-\sqrt{2}-i\sqrt{2})}{2}=\dfrac{(-\sqrt{2}-2)-i\sqrt{2}}{2}\).
✓ Two roots \[ z = \frac{(\sqrt{2}-2)+i\sqrt{2}}{2} \quad\text{and}\quad z = \frac{-(2+\sqrt{2})-i\sqrt{2}}{2} \]
Problem A1 — Show \(\left(\dfrac{z}{r}\right)^{1/n} = \dfrac{z^{1/n}}{r}\) for \(z\in\mathbb{C},\,r>0,\,n\in\mathbb{N}\)
Strategy Write \(z\) in polar form, apply the \(n\)th-root formula to each side, and confirm they agree.
  • 1Write \(z = |z|e^{i\theta}\). Then \(\dfrac{z}{r}=\dfrac{|z|}{r}e^{i\theta}\).
  • 2Left side — the set of \(n\)th roots of \(\dfrac{z}{r}\): \[ \left(\frac{z}{r}\right)^{1/n} = \left(\frac{|z|}{r}\right)^{1/n}\exp\!\left(i\,\frac{\theta+2\pi k}{n}\right), \quad k=0,\ldots,n-1 \]
  • 3Right side — compute \(z^{1/n}\) first, then divide by \(r\): \[ z^{1/n} = |z|^{1/n}\exp\!\left(i\,\frac{\theta+2\pi k}{n}\right), \quad k=0,\ldots,n-1 \] \[ \frac{z^{1/n}}{r} = \frac{|z|^{1/n}}{r}\exp\!\left(i\,\frac{\theta+2\pi k}{n}\right), \quad k=0,\ldots,n-1 \]
  • 4Since \(r>0\), we have \(\dfrac{|z|^{1/n}}{r}=\left(\dfrac{|z|}{r}\right)^{1/n}\) (real positive numbers). So the two expressions are identical for every \(k\). \(\blacksquare\)
✓ Conclusion The set of \(n\)th roots of \(z/r\) equals the set \(\{w/r : w \text{ is an } n\text{th root of }z\}\), so \(\left(\dfrac{z}{r}\right)^{1/n} = \dfrac{z^{1/n}}{r}\).
